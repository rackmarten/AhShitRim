# AhShitRim cheat codes

Type them while CJ has the player (F10), as in San Andreas: no console, just the letters (and the top row's digits), anywhere but in a menu. The help box top left says "Cheat activated", or "Cheat deactivated" when a toggle goes off. While CJ has the player M doesn't open Skyrim's map (codes have it in the middle); the map is in Tab's menu.

San Andreas keeps only a key of each code (a checksum of its letters), so every spelling with the same key works, as it does in San Andreas: the "also" column has the best-known ones. San Andreas's toggles are off again after a load, as in San Andreas; NOMERCY stays on in the save.
